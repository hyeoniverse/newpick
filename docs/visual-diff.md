# 화면 전 · 후 비교 (#229)

리팩토링처럼 **화면이 바뀌면 안 되는 PR**에서, 바꾸기 전과 뒤의 화면을 찍어 픽셀로 비교합니다.

## 준비

- 웹 dev 서버(`apps/web`에서 `npm run dev`, 3000)와 api(3001)를 켜 둡니다. 도구가 서버를 켜거나 끄지 않습니다.
- 로그인한 화면은 `apps/api/.env`의 `JWT_SECRET`으로 시험용 토큰을 만들어 찍습니다 (로컬 전용).
  관리자 · 마이페이지까지 보려면 관리자 계정 id를 `VISUAL_USER_ID`로 줍니다.

## 쓰는 법

```sh
cd apps/web
# 1. 바꾸기 전 (main에서)
VISUAL_USER_ID=<관리자 id> npm run visual:shots -- before
# 2. 코드를 바꾼 뒤 (작업 브랜치에서, dev 서버가 다시 컴파일한 다음)
VISUAL_USER_ID=<관리자 id> npm run visual:shots -- after
# 3. 비교
npm run visual:diff -- before after
```

- 사진은 `apps/web/.visual/<이름>/`에 쌓이고 git에 올라가지 않습니다.
- `visual:diff`는 사진마다 `=`(같음) · `≈`(잡음) · `≠`(다름) · `!`(사진 없음)을 보이고, 다른 것은 전 · 후를 나란히 붙인 사진을 `.visual/diff-<전>-<후>/`에 남깁니다. 다른 것이 있으면 종료 코드 1입니다.
- 일부만: `--modes desk-light,mobile`, `--only /admin` (경로 일부). 잡음 기준: `visual:diff -- a b --tolerance 0.02` (퍼센트, 기본 0.01).

## 찍는 것

`apps/web/visual/targets.mjs`에서 정합니다. 화면 · 열린 상태를 더하려면 이 파일만 고칩니다.

| | 지금 |
| --- | --- |
| 화면 | 23개 (공개 9 · 마이페이지 5 · 관리자 9) |
| 방식 | 데스크톱 라이트 · 데스크톱 다크 (1280px) · 휴대폰 (390px) |
| 열린 상태 | 휴대폰 메뉴 · 휴대폰 검색 · 로그인 시트 (로그아웃, 데스크톱 · 휴대폰) |

## 찍을 때 막는 것 (매번 달라져 차이로 잡히는 것)

- 애니메이션 · 전환 효과, 자동으로 넘어가는 슬라이더(첫 자리로), 차트 캔버스, Next 개발 도구 표시, 형광펜 팝업
- **조회수 올리기 · 방문 기록 요청은 보내지 않습니다.** 보내면 찍을 때마다 조회수와 관리자 통계의 숫자가 바뀝니다 (로컬 데이터도 더러워지지 않습니다)

## 알려진 차이

- 시간이 흐르면 바뀌는 글자(로그인 기기의 "최근 활동 N시간 전" 등)는 전 · 후 사이가 길면 차이로 잡힙니다. 나란히 붙인 사진으로 확인합니다.
- 관리자 통계의 취향 점수 목록에서 점수가 같은 태그의 순서가 찍을 때마다 바뀔 수 있습니다 (api가 점수만으로 정렬, 따로 고칠 것).
